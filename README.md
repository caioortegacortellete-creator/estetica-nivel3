# Clínica de Estética — Nível 3 (Premium)

Site modelo da **Highway Agência** para clínicas de estética, plano Nível 3. Site de várias páginas, com dois rostos revelados por um rastro do mouse no topo, antes e depois, tratamentos em penteadeira, quiz e ficha de avaliação que abre o WhatsApp.

Dados fictícios (Clínica Alba, Cascavel/PR) e imagens ilustrativas, apenas para demonstração.
